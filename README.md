# VANTA Hypercars

Учебный одностраничный сайт по изображениям из «задание 2.docx». Node.js 24 и SQLite, без сторонних зависимостей.

## Запуск

```sh
npm start
```

Откройте http://localhost:3000. База автоматически создаётся в `data/vanta.sqlite`.

## Возможности

- Каталог восьми автомобилей, фильтры, просмотр характеристик и выбор модели.
- Регистрация и вход; пароли защищены scrypt с уникальной солью.
- Серверные сессии в HttpOnly cookie и выход из аккаунта.
- Заявки сохраняются в SQLite и доступны только создавшему их пользователю.
- Адаптивная вёрстка, форма с проверкой полей, контакты и навигация.

## Проверка

```sh
npm test
```

Тест проверяет регистрацию, повторный email, неправильный пароль, сохранение заявки, изоляцию аккаунтов, выход и защиту от запросов с чужого сайта. Он использует отдельную временную БД.

## Структура

`dist/` — клиентская часть; `server.mjs` — HTTP API и SQLite; `test/` — интеграционный тест. Данные пользователей не включаются в Git.

Изображения автомобилей отображаются из скриншотов документа с кадрированием через CSS. Два автомобиля на скриншотах показаны не полностью: их недостающие характеристики дополняют учебный каталог. Макет воспроизведён по образцу, точное совпадение шрифта не гарантируется. Это демонстрационный проект, не официальный сайт дилера. Заявки сохраняются локально, дилеру не отправляются.

Для размещения полного проекта нужен сервер Node.js с постоянным диском. GitHub Pages запускает только статическую часть и не поддерживает SQLite/API. В production используйте HTTPS, NODE_ENV=production, резервное копирование БД и внешний reverse proxy.
